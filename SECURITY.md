# Security Policy

This is a small, personal example project, not a service with a support
contract — but reports are still welcome.

## Reporting a vulnerability

Please open a private report via
[GitHub's security advisory form](https://github.com/matthews-wong/devops-docker-tooling-3/security/advisories/new)
rather than a public issue. Include the affected file/commit and, if
applicable, steps to reproduce.

There's no fixed SLA, but reports are triaged as they come in and a fix or
mitigation is prioritized over new feature work.

## Supported versions

Only the `main` branch is maintained; there are no tagged releases to
backport fixes to.
